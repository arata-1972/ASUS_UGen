# v6 實際操作影片腳本

142.76秒。使用實際操作畫面截圖剪輯；不是連續螢幕錄影。輸入為自家合成台語音訊，全編配自家華語TTS說明旁白。ASR、翻譯、TTS呼叫自家伺服器，UGen硬體尚未整合。

## 場景 1｜0–18.28秒

TaiwaneseSpeechBridge

我們希望讓只說台語的來訪者，也能和說華語的服務人員溝通。這次展示，是可以操作的語音轉文字、翻譯和語音播放原型。

## 場景 2｜18.28–33.0秒

來訪者問：服務台在哪裡？

先用自家翻譯和台語語音合成，製作「請問服務台在哪裡」的台語測試音檔。這是合成音訊，不是真人錄音。

## 場景 3｜33.0–51.36秒

選擇 WAV → 音訊轉文字

在實際畫面選擇台語，上傳剛才的音檔，按下音訊轉成文字。程式真正呼叫自家伺服器，這次辨識花了約零點八秒。

## 場景 4｜51.36–69.2秒

確認原文，修正辨識錯誤

辨識結果有錯字。我們沒有把它當作正確答案，而是參照原來的測試句，修正成「請問服務台佇佗位」。使用者確認原文，才進行翻譯。

## 場景 5｜69.2–85.08秒

翻譯成華語，確認內容

按下翻譯後，實際得到「請問服務台在哪裡」。這次翻譯約零點二秒。使用者仍可修改翻譯內容，再決定是否播放。

## 場景 6｜85.08–102.76秒

播放已確認的翻譯

確認後按下播放翻譯，實際產生華語音訊並播放。這次語音合成約一點一秒。服務人員可以聽到問題，再回覆來訪者。

## 場景 7｜102.76–121.76秒

現有自家 API → 未來現場部署

目前文字辨識、翻譯和語音合成在自家伺服器執行。下一步是把適合的模型部署到現場電腦連接的競賽設備，驗證效能。還沒有完成硬體整合。

## 場景 8｜121.76–142.76秒

先確認，再讓對方聽懂

這個原型不使用大型語言模型，也不自動決定工作。它讓雙方確認文字後，用對方的語言播放。接下來要用真人語音測試品質，並完成指定設備的驗證。
