# 台語語音任務卡 / 台湾語音声タスクカード

ASUS UGen AI League 2026 · Workplace AI · Stage I · v3

## 繁體中文

### 用途
使用者以台語說出工作需求，透過 Taigi AI Labs 的既有外部 API 取得文字及翻譯，再由規劃中的 UGen 裝置小型語言模型整理為任務卡。使用者確認與修改後才儲存任務。本作品不會自動發送訊息或執行工作。

### 本次文件範圍與狀態
這是新應用的 Stage I 設計文件及模擬展示。模擬介面使用預設示例資料，沒有呼叫真實 API、語言模型或 UGen 硬體。尚未完成 UGen 硬體整合，尚無實測效能數值。

### 系統流程
主機是使用者操作的電腦，負責錄音、呼叫外部服務與顯示畫面。UGen300 是連接主機的 AI 加速裝置。

使用者在主機錄下台語音訊 → 主機呼叫外部 Taigi LID／STT／必要的翻譯 API → 外部 API 將文字回傳主機 → 主機把文字交給連接的 UGen300 執行小型語言模型推論 → 任務欄位回到主機 → 主機檢查格式，顯示任務卡 → 使用者修改、確認後儲存。確認內容可透過外部 Taigi TTS API 朗讀。語音服務需要網路；UGen 負責把文字整理成工作卡。本構想不是完全離線的系統。

### 任務欄位與安全檢查
動作、對象、原文明示的時間、待確認項目、來源文字。不補造未提供的人員或日期；欄位不完整或結構無效時請使用者補充。確認前不執行任務。

### 在現場整理工作的意義
語音轉寫後，工作卡整理可在現場連接的 UGen 執行，不需再把同一段文字送給另一個雲端語言模型。這個分工的實際速度、記憶體使用量及可用性，需與主機 CPU 比較後確認。

### Stage II 計畫
接收並配置指定 UGen 硬體，確認相容主機、runtime、可部署模型與授權條件。模型尚未選定。將模擬處理替換為 UGen 實際推論，檢查輸出格式、錯誤恢復、取消與使用者確認。若模型、設定與輸入可對齊，再比較主機 CPU 與 UGen 的任務整理時間；記錄各階段時間、成功率、欄位正確率、記憶體使用量、人工修正量與裝置執行證據。比較方法與指標均為開發計畫，尚無實測結果。

### 未來部署構想：內部伺服器與多個終端
Stage I 仍為設計與模擬。近期構想使用既有外部 Taigi 語音 API；不能將此架構稱為完全離線。
我們正在開發可部署於企業內部的台語語音辨識、翻譯與語音合成。未來計畫把這些 Taigi 語音 AI 與 UGen 的工作整理功能結合，由連接 UGen 的企業內部電腦或伺服器接收多個電腦／平板的請求，在企業內部完成語音與工作整理，再把草稿回傳原終端，由使用者確認。
這是未來擴充方案，尚未實作或驗證。模型支援、同時請求數、排程、記憶體、速度、權限與資料保存方式須在開發時確認。目前的外部音訊處理仍需網路。未來的企業內部部署及多終端使用尚在開發／規劃階段，不能視為已完成。

### 背景技術與權利歸屬
台語語言判定、語音辨識、翻譯及語音合成 API 是 Taigi AI Labs LLC 參賽前已有的背景技術。本套文件不包含背景 API 的伺服器端原始碼、模型或權重。此次新作品範圍為應用邏輯、任務確認介面、串接說明及展示素材。

### 資料與認證
展示案例為合成工作情境，不含客戶資料。此套件不含 API 金鑰、環境變數秘密、模型權重或真實錄音。API 端點與認證方式將於開發階段依授權文件處理。

## 日本語全文訳

### 用途
利用者が台湾語で仕事の依頼を話し、Taigi AI Labs の既存外部 API で文字と翻訳を取得し、計画中の UGen 上の小型言語モデルでタスクカードに整理します。利用者が確認・修正してから保存します。本作品はメッセージ送信や業務実行を自動で行いません。

### 今回の文書の範囲と状態
新アプリの Stage I 設計文書と模擬展示です。模擬画面は固定の例示データを使用し、実際の API、言語モデル、UGen ハードウェアを呼び出していません。UGen ハードウェア統合は未完了で、実測性能値はありません。

### システムの流れ
ホストは利用者が操作するパソコンで、録音、外部サービスの呼び出し、画面表示を担当します。UGen300 はパソコンに接続する AI 計算装置です。

利用者がホストで台湾語音声を録音 → ホストから外部 Taigi LID／STT／必要な翻訳 API を呼ぶ → 外部 API が文字をホストへ返す → ホストが接続された UGen300 に文字を渡し、小型言語モデルで推論する → タスク項目をホストへ返す → ホストが形式を検査し、カードを表示 → 利用者が修正・確認して保存。確認内容は外部 Taigi TTS API で読み上げられます。音声サービスには通信が必要で、UGen は文字を作業カードに整理します。本構想は完全オフラインのシステムではありません。

### タスク項目と安全確認
動作、対象、原文で明示された時刻、確認待ち項目、元の文字。与えられていない人員や日付を作らず、不完全な項目や無効な構造は利用者に補足を求めます。確認前にタスクを実行しません。

### 現場で仕事を整理する意味
音声を文字にした後は、現場に接続した UGen でカードを整理し、同じ文章を別のクラウド言語モデルへ再送する必要を減らします。この役割分担の速度、メモリ使用量、使いやすさは、ホスト CPU と比較して確認します。

### Stage II 計画
指定 UGen ハードウェアを受領・設定し、対応ホスト、runtime、配置できるモデルと許諾条件を確認します。モデルは未選定です。模擬処理を実際の UGen 推論に置き換え、出力形式、エラー回復、キャンセル、利用者確認を検証します。モデル・設定・入力をそろえられる場合は、ホスト CPU と UGen のタスク整理時間を比較します。各段階の時間、成功率、項目正答率、メモリ使用量、手修正量、装置実行の証拠を記録します。比較方法と指標は開発計画で、実測結果はありません。

### 将来の配置構想：社内サーバーと複数端末
Stage I は設計と模擬の段階です。直近の構想は既存の外部 Taigi 音声 API を使用するため、完全オフラインとは呼べません。
企業内に設置できる台湾語の音声認識・翻訳・音声合成を開発中です。将来はこれらの Taigi 音声 AI と UGen の仕事整理を組み合わせ、UGen を接続した社内 PC またはサーバーが複数 PC／タブレットからの依頼を受け付け、社内で音声処理と仕事整理を行う計画です。草案を元の端末へ返し、本人が確認します。
将来の拡張案であり、実装や検証はまだ行っていません。モデル対応、同時依頼数、処理順序、メモリ、速度、権限、保存方法は開発時に確認します。現在の外部音声処理には通信が必要です。将来の社内配置と複数端末利用は開発・計画段階で、完成済みとは扱いません。

### 背景技術と権利帰属
台湾語の言語判定、音声認識、翻訳、音声合成 API は Taigi AI Labs LLC が参加前から保有する背景技術です。本書類には背景 API のサーバー側ソースコード、モデル、重みを含みません。今回の新作品の範囲はアプリ処理、タスク確認画面、連携説明、展示素材です。

### データと認証
展示例は合成の業務場面で、顧客データを含みません。本パッケージには API キー、環境変数の秘密、モデルの重み、実録音を含みません。API の接続先と認証方法は開発時に許諾文書に従って扱います。
