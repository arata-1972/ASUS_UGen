# Taiwanese Speech Bridge

ASUS UGen AI League 2026 · Workplace AI · Stage I · v7

## What it does

Speech Bridge helps a Taiwanese-speaking visitor and a Mandarin-speaking receptionist understand one short turn at a time. The user selects a language and WAV file, checks and edits the recognised text, translates it, checks and edits the translation, then generates speech for the other person. No LLM, summary, task card or automatic business action is required.

## Implemented prototype and evidence

The localhost browser interface and CLI are implemented. Twelve protocol and failure-handling tests pass. The current inference backend calls existing self-hosted ASR, EOLE translation and TTS services. Running the interface on a local computer does not mean model inference runs on that computer or ASUS hardware. WAV upload is implemented; microphone recording is not implemented.

The reception demonstration uses a Taiwanese question generated by our own translation and TTS services. Actual ASR returned an error; the operator explicitly corrected the original sentence, then checked the translation before generating Mandarin speech. Browser playback was verified; browser file saving was not verified. Single-stage API measurements were approximately 803 ms for ASR, 189 ms for translation and 1,147 ms for TTS. They include networking and exclude human editing time. They are not accuracy, real-speaker quality or accelerator benchmarks.

Separate earlier CLI integration evidence is preserved: the forward Mandarin→Taiwanese run generated speech but initially rejected an unconfigured audio-hosting origin; that generated audio was recovered. The reverse Taiwanese→Mandarin ASR/translation/TTS run completed in 7,069.29 ms. These are distinct test inputs and measurements. Recognition errors are retained rather than replaced by expected answers.

## Proposed Thunderstorm deployment

For Stage II, we propose validating ASR on the designated Intel Arc Pro B70/OpenVINO environment. ASUS officially specifies B70 with 32 GB VRAM. Proprietary model compatibility, export, actual selected-GPU execution, memory and comparable CPU/GPU results remain unverified. Translation and TTS can initially remain on existing services while their device compatibility is evaluated. Hailo/UGen300 and B70/OpenVINO adapters are not implemented; the client returns explicit errors rather than silently substituting remote inference.

## Background technology and publication boundary

Existing ASR, translation, Taiwanese/Mandarin TTS and language detection are Taigi AI Labs background technology. This repository contains the new client, integration logic, interface, tests and selected synthetic demonstration evidence. It excludes existing backend service code, proprietary model weights, training data, credentials and customer recordings. Configuration examples use loopback placeholders; users supply authorised endpoints and private credentials. No new licence is granted for models/data and no licence file is added without an owner decision.
