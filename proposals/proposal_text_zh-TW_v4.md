# 台語語音任務卡

## 1. 繁體中文

台語語音任務卡

把台語工作交辦整理成可確認的任務卡

Taigi AI Labs LLC｜日本・2025 年成立｜2 人團隊

## 2. 繁體中文

口頭交辦可能不完整，先整理再確認

把模糊的台語工作指示，整理成使用者可核對的任務卡

應用情境：現場整理、物料準備與日常工作交辦。
口頭指示可能沒有說明負責人、時間或具體對象。
將原文與工作欄位一起顯示，讓使用者補充與確認。
未指定的負責人保持「待確認」，模型不擅自決定。
預期成果：減少重新輸入，留下經本人確認的工作紀錄。

## 3. 繁體中文

使用者逐步確認任務內容

錄音 → 轉寫 → 整理 → 修改 → 確認儲存

1　使用者以台語說出工作內容。
2　現場電腦呼叫 Taigi API，取得轉寫及必要的翻譯文字。
3　電腦控制連接的 UGen300，用小型語言模型整理工作欄位。
4　使用者核對原文、修改欄位並補上缺少的資訊。
5　確認後儲存；可選擇呼叫外部台語 TTS 回讀。

## 4. 繁體中文

現場電腦控制 API 串接與 UGen 推論

規劃架構：語音處理使用外部 API，工作整理在連接的 UGen 執行

現場電腦：錄音並呼叫 Taigi API
Taigi 外部 API：判定語言、轉寫／翻譯，回傳文字
現場電腦：接收文字，啟動 UGen 推論
UGen300：小型語言模型整理工作卡草稿
電腦／使用者：格式驗證 → 修正 → 確認後儲存
選用：Taigi TTS：電腦呼叫 API，取得台語語音回饋

## 5. 繁體中文

任務卡範例：缺少負責人就請使用者補上

模擬華語轉寫：明天下午三點前，把倉庫的包裝材料整理好。

工作：整理包裝材料
對象：倉庫的包裝材料
時間原文：明天下午三點前
負責人：待確認 → 使用者填入「現場負責人」
保留原文；經使用者確認後才儲存。
此為合成情境與模擬輸出，非實測辨識或 UGen 推論結果。

## 6. 繁體中文

工作整理在現場 UGen 執行

減少工作整理對雲端語言模型的依賴

現場電腦取得 Taigi API 回傳的轉寫／翻譯文字。
電腦端推論控制程式，把文字送入連接的 UGen300。
UGen 上的小型語言模型推論產生工作欄位草稿。
電腦檢查格式並呈現結果，使用者確認後才儲存。
模型與執行環境尚未選定，將依官方支援清單測試。
音訊處理仍需外部 API 與網路，不是完全離線應用。

## 8. 繁體中文

確認流程與失敗處理

任務卡不自動變成外部指令

保留原文，讓使用者核對轉寫與整理結果。
未提供期限或負責人時，顯示待確認資訊。
格式不符時拒絕儲存，轉為手動修正。
API 失敗或網路中斷時，顯示狀態並允許重新操作。
音訊／必要文字送至外部 API；任務卡由主機保存。
競賽展示使用合成內容，不使用客戶資料。
